الدخول

اللوحة دي بتعدل الموقع على GitHub مباشرة. محتاجة «مفتاح» من GitHub مرة واحدة بس:
  1. افتحي github.com ← الصورة الشخصية ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. في Repository access اختاري Only select repositories واختاري ريبو الموقع بس.
  3. في Permissions ← Contents اختاري Read and write، وبعدين Generate token.
  4. انسخي المفتاح وحطيه هنا. المفتاح بيتحفظ على الجهاز ده بس، وماتبعتهوش لحد.
ده وضع معاينة: تقدري تجربي كل حاجة، بس التعديلات مش هتتنشر على الموقع. عشان تنشري لازم تدخلي بمفتاح GitHub بعد ما الموقع يترفع.
اسم القسم بالعربي والإنجليزي ولونه وأيقونته. الصور اللي على كارت القسم بتتاخد من أول 3 كتب فيه.
في العنوان الكبير: الكلمة بين [ ] بتطلع صفرا، والكلمة بين { } بتطلع تركواز، وكل سطر جديد بيبقى سطر جديد.
